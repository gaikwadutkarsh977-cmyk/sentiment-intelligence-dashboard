# Sentiment Intelligence Dashboard

## Project Overview
This project is an interactive Sentiment Analysis Dashboard built using Python and Streamlit. It analyzes user text and classifies the sentiment as Positive, Negative, or Neutral using Natural Language Processing (NLP) techniques.

## Problem Statement
Businesses receive large volumes of customer feedback from social media, reviews, and surveys. Manually analyzing this data is difficult. This project helps automatically analyze customer sentiment.

## Features
- Analyze user text sentiment
- Upload CSV file for batch sentiment analysis
- Visualization of sentiment results
- Word cloud for most frequent words

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- NLP
- Matplotlib

## Project Workflow
1. Data input from user
2. Text preprocessing
3. Sentiment prediction using ML model
4. Visualization of results
